# PRD 模板（docs/PRD.md）

> 使用方式：让 AI 按本骨架填充；每节不得为空，"暂不实现项"必须显式列出。

---

## 1. 产品目标与私有化定位

- 一句话目标：【例：搭建一个只给自己用的工作生活管理台，脱离任何云端账号】
- 使用者：【单人，非公开产品】
- 私有化含义：数据 100% 存于本机文件；无登录、无账号、无网络依赖；可整体拷贝/备份迁移
- 成功标志：【例：日常所有记录都在一个本地页面里完成，重启清缓存不丢数据】

## 2. 典型使用场景

| # | 场景 | 触发 | 期望结果 |
|---|---|---|---|
| 1 | 【添加今日计划 → 同步至首页总览】 | 在计划模块新增一条今日计划 | 首页总览当日区域立即出现该条，无需刷新 |
| 2 | 【自媒体选题推进】 | 在灵感库记录选题 | 可依次推进到策划/制作/发布，已发布可录数据 |
| 3 | 【开发 Bug 录入】 | 发现 Bug | 在对应项目下录入含严重级别与状态的条目，可筛选 |
| 4 | 【客户沟通追踪】 | 与客户沟通后 | 在客户档案追加一条带时间的沟通记录 |
| 5 | 【健康日历回看】 | 查看昨天吃了什么 | 日历按日期展示当天健身与饮食记录 |

## 3. 完整页面结构

### 3.1 全局布局
- 左侧导航栏：【首页总览、自媒体、开发、咨询、健康、娱乐】+ 底部【设置/主题切换】
- 上方工具栏：【全局搜索、新增按钮、主题切换、备份状态】
- 中央内容区：模块页面容器

### 3.2 各模块页面
（每模块写：页面区块、字段、交互、状态流转）

- **首页总览**：今日计划区 / 模块待办汇总区 / 快捷入口
- **自媒体**：五步流程流 + 灵感列表 + 已发布数据表
- **开发**：项目列表 → 里程碑 → Bug 表
- **咨询**：客户列表 → 客户详情（沟通记录时间线）
- **健康**：日历视图 + 当日健身/饮食录入
- **娱乐**：分类标签 + 条目列表

- 跨模块联动：【今日计划新增 → 首页总览同步】

## 5. 本地持久化与备份机制

- 存储位置：【项目根目录 data/ 下】
- 格式：【SQLite / JSON 文件】
- 写入时机：【每次增删改立即落盘】
- 自动备份策略：【每次写入后生成备份到 backups/，保留最近 N 份】
- 恢复步骤：【从 backups/ 复制回 data/ 覆盖】
- 验证方式：【重启程序 + 清浏览器缓存后数据仍在】

| # | 维度 | 验收项 | 判定方式 | 通过 |

| 3 | 数据持久性 | 【重启后数据不丢】 | 【人工+测试】 | ☐ |
| 4 | 数据持久性 | 【清浏览器缓存后数据不丢】 | 【人工】 | ☐ |
| 5 | 数据持久性 | 【自动备份生成且可恢复】 | 【测试】 | ☐ |
| 6 | 数据联动性 | 【今日计划新增后首页总览同步出现】 | 【测试】 | ☐ |
| 7 | 数据联动性 | 【自媒体阶段推进后列表状态正确】 | 【测试】 | ☐ |
| 8 | 模块交互完整性 | 【各模块增删改查全部可用】 | 【测试】 | ☐ |
| 9 | 模块交互完整性 | 【Bug 可录入、客户可删除、健康日历可按日期查看】 | 【测试】 | ☐ |
| 10 | 范围管控 | 【未出现登录/联网/手机端实现】 | 【人工】 | ☐ |

## 7. 暂不实现项（第一版明确不做）

- 多用户权限 / 账号体系
- 登录注册
- 云同步 / 联网部署
- 手机端 / App 封装
- 团队协作
- 【其他 AI 自行提出的扩展，必须显式拒绝】
