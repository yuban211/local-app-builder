# 第一版验收清单（逐条判定）

> 依据 PRD 第 6 节派生。每一项必须有明确的通过/不通过与证据，不能只写"OK"。

## A. 运行稳定性
- [ ] A1 双击 `scripts/start.bat`（Windows）/ `start.command`（macOS）/ `start.sh`（Linux）可启动本地服务
- [ ] A2 脚本自动打开浏览器并显示首页，无控制台报错
- [ ] A3 连续运行 1 小时不崩溃、不内存异常增长
- [ ] A4 依赖缺失或启动失败时，脚本给出可读的错误原因与修复提示

## B. 数据持久性（私有化红线）
- [ ] B1 数据写入真实本地文件（data/ 目录），不依赖浏览器缓存 / localStorage / sessionStorage
- [ ] B2 关闭程序后重新打开，全部数据仍在
- [ ] B3 清除浏览器缓存后重新打开，数据仍在
- [ ] B4 每次写入后自动生成备份到 backups/
- [ ] B5 从备份可完整恢复数据
- [ ] B6 数据库/数据文件损坏时，程序不整体崩溃（至少能从备份恢复）

## C. 数据联动性
> 以下为示例模块校验项；真实项目请按 PRD 第 4 节的实际模块与跨模块联动逐条改写。
- [ ] C1 新增【模块A】一条数据后，相关汇总/联动处立即出现该条
- [ ] C2 【模块A】流程推进后，列表状态与统计正确
- [ ] C3 【模块B】数据录入后，相关统计数值正确累加
- [ ] C4 【模块B】子项进度与所属父项一致
- [ ] C5 【模块C】记录按时间顺序展示，归属正确
- [ ] C6 【模块D】记录按日期正确聚合

## D. 模块交互完整性
> 以下为示例；按 PRD 实际模块逐条改写，确保每个模块的增删改查与关键交互都覆盖。
- [ ] D1 首页总览：增 / 改 / 删 / 查 全可用
- [ ] D2 【模块A】：核心流程可推进，条目可增删
- [ ] D3 【模块B】：各实体均可录入；可按关键字段筛选
- [ ] D4 【模块C】：条目可增、可删（级联）；记录可追加
- [ ] D5 【模块D】：记录可录入，可按日期查看
- [ ] D6 其余模块：条目可增删，可分类筛选
- [ ] D7 危险操作（删除等）有二次确认
- [ ] D8 空列表有明确空状态提示，不出现空白页
