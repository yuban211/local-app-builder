# 第一版验收清单（逐条判定）

> 依据 PRD 第 6 节派生。每一项必须有明确的通过/不通过与证据，不能只写"OK"。

## A. 运行稳定性
- [ ] A1 双击 `scripts/start.bat`（Windows）/ `start.command`（macOS）/ `start.sh`（Linux）可启动本地服务
- [ ] A2 脚本自动打开浏览器并显示首页，无控制台报错
- [ ] A3 连续运行 1 小时不崩溃、不内存异常增长
- [ ] A4 依赖缺失或启动失败时，脚本给出可读的错误原因与修复提示

## B. 数据持久性（私有化红线）
- [ ] B1 数据写入真实本地文件（data/ 目录），不依赖浏览器缓存 / localStorage / sessionStorage
- [ ] B2 关闭程序后重新打开，全部数据仍在
- [ ] B3 清除浏览器缓存后重新打开，数据仍在
- [ ] B4 每次写入后自动生成备份到 backups/
- [ ] B5 从备份可完整恢复数据
- [ ] B6 数据库/数据文件损坏时，程序不整体崩溃（至少能从备份恢复）

## C. 数据联动性
- [ ] C1 新增今日计划后，首页总览当日区域立即出现该条
- [ ] C2 自媒体选题阶段推进后，列表状态与统计正确
- [ ] C3 已发布内容的数据录入后，统计数值正确累加
- [ ] C4 开发模块里程碑进度与所属项目一致
- [ ] C5 咨询沟通记录按时间顺序展示，归属客户正确
- [ ] C6 健康记录按日期正确聚合到日历

## D. 模块交互完整性
- [ ] D1 首页总览：增 / 改 / 删 / 查 全可用
- [ ] D2 自媒体：五步流程流可推进，灵感库可增删
- [ ] D3 开发：项目、里程碑、Bug 均可录入；Bug 可按严重级别与状态筛选
- [ ] D4 咨询：客户可增、可删（级联）；沟通记录可追加
- [ ] D5 健康：健身与饮食可录入，可日历化按日期查看
- [ ] D6 娱乐：条目可增删，可分类筛选
- [ ] D7 危险操作（删除客户等）有二次确认
- [ ] D8 空列表有明确空状态提示，不出现空白页

## E. 范围管控
- [ ] E1 无登录 / 注册 / 账号体系
- [ ] E2 无联网依赖、无云同步、无外部 API 调用（除本地服务自身）
- [ ] E3 无手机端实现
- [ ] E4 代码中不存在 PRD"暂不实现项"列出的功能

## F. 交付物
- [ ] F1 `docs/PRD.md` 存在且六维度完整
- [ ] F2 `docs/开发计划.md` 存在且含 9 阶段、测试节点、交付物
- [ ] F3 `docs/走查报告.md` 存在且缺陷已分级
- [ ] F4 Git 仓库已初始化，首次提交消息为 `完成木子工作台V1.0`
- [ ] F5 每个缺陷修复对应一次独立 commit
- [ ] F6 README 含启动方式与改造路径
- [ ] F7 完整 ZIP 包已生成（不含可再生依赖）
